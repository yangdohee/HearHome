# HearHome
청각 장애인이 자신만의 공간인 집에서 조금 더 편안하고 안심하며 생활할 수 있도록 돕는 "AI기반 가정 내 소리 인식 알림 시스템"이다. 강아지 짖는 소리, 초인종, 세탁기 종료음 등 집 안에서 감지하고 소리를 사용자가 직접 등록하고, 해당 소리가 감지되면 화면으로 알림을 띄운다. 또한 언제 어떤 소리가 발생했는지 기록하고 소리의 패턴을 분석해 집 안의 상황을 파악하는데 도움을 줄 것이다. 이를 통해 소리를 듣지 못해 생기는 불안함을 줄이고, 적어도 자신만의 공간인 집에서 만큼은 조금 더 편안하고 안심하며 생활할 수 있도록 돕는 것이 이번 프로젝트의 최종 목표이다.
